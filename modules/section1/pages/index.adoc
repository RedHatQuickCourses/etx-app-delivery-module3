In this section, you'll build a complete cloud-native Continuous Integration (CI) workflow using OpenShift Pipelines (Tekton).

You'll create a reusable CI pipeline, securely retrieve registry credentials from HashiCorp Vault, automate pipeline execution with GitLab webhooks and Tekton Triggers, and validate the end-to-end build process that produces container images for deployment on OpenShift.
