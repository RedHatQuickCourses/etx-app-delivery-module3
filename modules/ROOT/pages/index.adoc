== What's in this course?

In this training, you'll explore the role of platform services, Continuous Integration (CI) with **Red Hat OpenShift Pipelines**, Continuous Delivery (CD) with **Red Hat OpenShift GitOps**, and application promotion workflows. Through hands-on exercises, you'll build, test, deploy, promote, and roll back applications across environments using automated, GitOps-driven workflows.

By the end of the training, you'll understand how these capabilities work together to create a repeatable software delivery process that improves developer productivity, deployment consistency, security, and application delivery reliability.

Duration: 4.5 hours

== Objectives

On completing this course, you should be able to:

* Create and automate CI pipelines using OpenShift Pipelines and Tekton.
* Build and publish container images using automated workflows.
* Configure OpenShift GitOps and Argo CD for continuous deployment.
* Manage application deployment configuration using Git as the source of truth.
* Connect CI pipelines with GitOps workflows to automate application delivery.
* Promote application images across development and staging environments.
* Implement GitOps-based deployment and promotion workflows.
* Monitor application deployments and verify observability and deployment status.
* Apply rollback strategies to restore applications to a previous version.
* Build a repeatable, automated path from source code to deployed and continuously managed applications.
