= Lab 12: Configure Quay for Image Promotion
:navtitle: Lab 12: Configure Quay
:experimental:

In this exercise, you'll prepare Quay for the image promotion workflow by creating the repository used by the promotion pipeline and storing robot account credentials securely in Vault.

By the end of this exercise, you will have:

* Created the `etx-app` organization and `etx-app-base-app` repository in Quay
* Created a robot account for non-interactive image promotion
* Stored the Quay robot credentials in Vault for use by the promotion pipeline

The promotion pipeline pushes images to Quay at `etx-app/etx-app-base-app` and retrieves authentication credentials from Vault at `secret/registry/quay`.

NOTE: Interactive users authenticate to Quay using Keycloak Single Sign-On, while CI/CD pipelines use robot accounts for automated, non-interactive authentication.

== Store Quay Credentials in Vault

Store the Quay robot account credentials in Vault so the promotion pipeline can retrieve them securely at runtime.

. Retrieve the Quay hostname:
+
[source,bash,role=execute]
----
oc get route -n quay \
  -l quay-component=quay-app-route \
  -o jsonpath='{.items[0].spec.host}' && echo
----
+
. Retrieve the Vault root token:
+
[source,bash,role=execute]
----
oc get secret etx-vault-bootstrap \
  -n vault \
  -o jsonpath='{.data.root-token}' | base64 -d && echo
----

. Open the *Vault* URL from your lab environment.
. Sign in using the **Token** authentication method and paste the token retrieved above.
+
.Sign in to Vault
image::vtoken.png[link=vtoken.png,width=400]
+
. From the Vault dashboard, open the `secret/` secrets engine.
+
.Secret Engine
image::secrets.png[link=secrets.png,width=600]
+
. Click btn:[Create secret].
+
.Create Secret
image::createsecret.png[link=createsecret.png,width=600]
+
. Create a secret with the path:
+
----
registry/quay
----
+
. Add the following key-value pairs:
+
* **server:** Quay hostname returned by the earlier command in Step 1 (without `https://`)
* **username:** `etx-app+promoter`
* **password:** Robot token copied from Quay
+
.Create Vault Secret
image::csecret.png[link=csecret.png,width=700]
+
. Click btn:[Save].
+
.Completed Secret
image::final.png[link=final.png,width=700]

NOTE: The promotion pipeline authenticates to Vault using Kubernetes authentication and retrieves these credentials automatically during execution. No Quay credentials are stored directly in the pipeline definition.
